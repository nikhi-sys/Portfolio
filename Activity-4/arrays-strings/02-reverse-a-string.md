# Reverse a String

## Problem / Difficulty
Reverse a string in-place.

**Difficulty:** Easy

## LeetCode Link
https://leetcode.com/problems/reverse-string/

## Approach
Use two pointers, one at the beginning and one at the end of the string.
Swap the characters at these positions and move the pointers toward the center.

## Complexity

**Time Complexity:** O(n)

**Space Complexity:** O(1)

## Notes
- Tested locally with a normal string: "hello" → "olleh".
- Tested an edge case with a single character: "a" → "a".
- LeetCode result: Accepted.
