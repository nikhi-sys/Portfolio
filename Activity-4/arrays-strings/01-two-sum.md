# Two Sum

## Problem / Difficulty
Given an array of integers and a target value, find two numbers whose sum equals the target and return their indices.

**Difficulty:** Easy

## LeetCode Link
https://leetcode.com/problems/two-sum/

## Approach
Use two nested loops to check every possible pair of numbers.
If the sum of two numbers equals the target, return their indices.

## Complexity

**Time Complexity:** O(n²)

**Space Complexity:** O(1)  
(Excluding the memory used for the returned result.)
